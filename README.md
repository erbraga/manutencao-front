# manutencao-front

<br>

## Descrição

Este projeto foi produzido como entrega final do módulo **Desenvolvimento Full Stack Básico** do curso de **Especialização em Desenvovimento Web** da PUC Rio.
Trata-se de um MVP (mímino produto viável) desenvolvido no formato SPA (Single page application ou aplicação em página única) com o objetivo de dar suporte à gestão de manutenções de veículos.
A aplicação foi desenvolvida em conjunto com uma API que persiste os dados em um banco de dados em um servidor, no entanto, funciona perfeitamente off line, sem persistência dos dados.

<br>

## Instalação

A instalação é extremamente simples e não depende de nenhuma tecnologia que não seja padrão em um computador comum com conexão à internet. Basta seguir os passos abaixo 

1. Faça o download em https://github.com/erbraga/manutencao-front/archive/refs/heads/main.zip.

2. Crie um diretório e extraia os arquivos.



<br>

## Como executar

Para executar basta abrir o arquivo index.html no navegador.
O layout do aplicativo foi projetado para ser responsivo, por isso muda caso seja executado em modo tablet ou celular.  

<br>

## Funcionalidades

A tela se divide em 3 áreas com suas respectivas funcionalidades:
- **Cabeçalho:** Exibe o veículo selecionado e data e quilometragem atuais.
    - **Funcionalidades:** Cadastrar e selecionar os veículos utilizados e informar a data e quilometragem atuais.

<br>

- **Formulário:** Janela de cadastro de novos ítens de manutenção:

<br>

- **Tabela:** Exibe os ítens de manutenção cadastrados, filtrados por um veículo.
    - **Funcionalidades:** Listar os itens de manutenção associados ao veículo selecionado no cabeçalho, excluir estes ítens e atualizar a data da última manutenção para cada item.

<br>

## Tecnologias utilizadas


- **HTTP:** Protocolo de transmissão de dados utilizada para troca de dados entre o cliente e o servidor em uma aplicação web.

- **HTML:** Linguagem de marcação utilizada para definir o conteúdo de uma página web.

- **CSS:** Linguagem de de estilo utilizada para adicionar formatação à página web.

- **Javascript:** Linguagem de programação utilizada para adicionar comportamento à página web. 

- **Github:** Ferramenta de versionamento, que permite criar diversas versões do código durante o desenvolvimento da aplicação, além do seu compartilhamento.

- **Visual Studio Code (VSCode):** Ambiente de desenvolvimento integrado (IDE) que permite editar todo o código do projeto, escrito em diferentes linguagens, em um mesmo ambiente, integrando ainda outras ferramentas como **github**.
